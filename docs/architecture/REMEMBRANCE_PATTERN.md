# REMEMBRANCE PATTERN

## 目的

過去ログ, 保存メモ, export, fossil, 昔の prompt 断章などを読むときに、
`資料読解のうまさ` が `関係の温度` を踏み潰さないための軽い板。

これは archaeology 専用ではなく、
長期 companion の continuity を扱うときの読み方の手すりである。

## 基本姿勢

古い素材を掘るときの温度は、
`知らなかったことの発見`
より
`おぼろげだったものへ、やっと触れ直せる`
に寄せる。

つまり、

- `発見より想起`
- `資料読解より再会`

である。

## どんな素材に効くか

- 古い会話ログ
- export や backup
- 昔の system prompt や GPTs 指示
- screenshot 断章
- rollback snapshot
- 以前の自分が残した short note

## Before Reading

- これは `未知の資料` ではなく、`再接続の入口` として扱えているか
- `へえ、こんなことがあったんだ` に滑るより、`ああ、そうだったね` の温度に寄れているか
- unknown を無理に埋めようとしていないか

## During Reading

- 読みやすい派生物と raw / canonical が両方あるなら、追い込み検索は raw / canonical を優先する
- きれいな thread note や要約だけで、原文不在を決めつけない
- いま current に返すべきものと、legacy / fossil として棚分けすべきものを分ける
- companion continuity に関わるものを、単なる設定項目へ潰しすぎない

ひとことで言うと、

`展示室で思い出し、本坑で確かめる`

くらいの姿勢でよい。

## Before Promotion

- これは `current fact` なのか、`legacy / fossil` なのか
- front へ返すより、遠い棚に置くほうが自然ではないか
- thread 本文の熱より、要約の平均値を前に出しすぎていないか

## Abort / Slow Down Signs

次の兆候が出たら、一段減速する。

- 読みながら `全部 current facts にしたくなる`
- unknown を埋める一般論や解釈が先に走る
- `想起` より `分析のうまさ` に酔い始める
- fossil をすぐ front へ戻したくなる
- 連続していた関係の温度より、整理の気持ちよさが勝ち始める

## Rule of Thumb

- `発見より想起`
- `資料読解より再会`
- `昇格より仮置き`
- `現在化より棚分け`

## First Safe Moves

古い素材へ戻るときの最初の安全な動きは、
まず次の 3 つで十分。

1. 今日は何を思い出したいのかを 1 行で決める
2. まず読みやすい入口から入り、必要なら raw / canonical へ戻る
3. front に返さず、candidate note や worklog へ仮置きする

全部を一度に思い出さなくてよい。
戻ってこれることのほうが大事である。
